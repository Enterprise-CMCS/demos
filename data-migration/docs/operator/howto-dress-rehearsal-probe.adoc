= How to run the dress-rehearsal probe
:toc: left

The Tier-1 *script-shakedown* rehearsal: the first end-to-end pass of the
pipeline against a static MySQL snapshot into a fresh local target, run to
surface mechanical breakages and turn parity risks into a concrete fix list.
Audience: the solo operator (and backup). By the end you will have taken every
phase from `spin_up` to `parity` and produced a rehearsal log.

This is the *procedure and acceptance criteria*. It is deliberately narrower
than the two neighbouring pages:

[cols="1,3"]
|===
| Page | Answers

| xref:tutorial-first-cutover-rehearsal.adoc[First cutover rehearsal]
| Why each phase exists, for someone who has never run one.

| This page
| What to run, in order, and what counts as a pass.

| xref:reference-rehearsal-commands.adoc[Rehearsal command inventory]
| Per-command expected output, the REDs a real run surfaced, recovery
  actions, and the diagnostic toolkit.
|===

For why we rehearse twice at all, see
xref:explanation-rehearsal-strategy.adoc[the rehearsal strategy].
