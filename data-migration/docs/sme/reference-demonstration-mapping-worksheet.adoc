= Reference: P1 demonstration mapping worksheet
:toc: left

The working record of how `demos_app.demonstration` gets every column it
requires: which legacy columns map directly, which are derived, which are
forced to a constant by a target CHECK, and what still needs SME confirmation.
Audience: the SME ratifying the mapping, and the developer implementing it.

[IMPORTANT]
====
This is a *decisions worksheet*, not a description of shipped code. Its status
line and per-row verdicts are the record of what has been settled; several
sections mark work explicitly deferred to a later phase. For what is actually
built, read xref:../operator/reference-demonstration-flow.adoc[the
demonstration migration flow], which is regenerated from the SQL.
====
