= How-to: review a budget-neutrality JSONB payload (retired)

[IMPORTANT]
====
*This workflow is retired (SME decision, 2026-07-16).* Budget-neutrality
is out of scope for the migration -- it is DEMOS-owned. Users upload BN
workbooks (v2.14 format) into DEMOS, which validates them and writes
`demos_app.budget_neutrality_workbook` itself. The SME will translate the
existing v2.13 workbooks to v2.14 and upload them post-launch.

The migration no longer builds a BN aggregate, a `budget_neutrality` JSON
schema, or a BN parity check, so there is nothing here for an SME to
review. This page is kept only so existing links resolve.
====

There is no migration-side budget-neutrality payload to review. BN
validation happens inside DEMOS at upload time, against DEMOS's own
contract (the BN lambda writes `validation_data` as a `ValidationError[]`
array). See xref:explanation-data-shape-decisions.adoc[why
budget-neutrality is not migrated].
