= Reference: milestone date mapping
:toc: left

Which legacy phase-milestone dates become DEMOS `application_date` rows, how
`application_phase` is derived from them, and which legacy date columns are
deliberately deferred for SME review. Audience: the SME ratifying the mapping,
and the developer implementing it.

Read this alongside
xref:reference-pending-approved-rules.adoc[the pending/approved rules]: the same
2026-07-10 SME answers set the coverage for both, and decision D9 (amendment
milestone dates) is re-opened in both.

[IMPORTANT]
====
Two things on this page are *gated, not built*: no amendment
`application_date` load exists yet (D9 awaits SME re-ratification), and the
`phase_3_*` clearance sub-dates are logged rather than mapped. The
"Gated build design" and "Deferred for SME review" sections below describe
intent, not shipped code.
====
